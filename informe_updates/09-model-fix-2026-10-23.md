# Model fix after the first AWS rehearsal (ADR-0042, finding 2026-10-23)

- **Changed:** freeman-0.3.0 / logreg-0.2.0 replace 0.2.0 / 0.1.0. Browser and
  OS are scored as families (Chrome, macOS…), not version strings. Freeman's
  population (`p_global`) is learned by the deployment, with the training data
  as a prior worth κ = 100 logins. The profile learns a login only if it ended
  in a session (ALLOW, or a passed step-up).
- **New numbers:** Freeman ROC-AUC 0.779 → 0.807, recall@1%FPR 0.105 → 0.132;
  LogReg recall@1%FPR 0.395 → 0.474 (ROC-AUC 0.873 → 0.865). RF / LGBM dropped
  (reference only).
- **Review:** every place that cites freeman-0.2.0, 0.779 / 0.105 or LogReg
  0.39/0.50; the model chapter's description of `p_global` (now
  deployment-adapted) and of what "successful login" means for learning; add the
  train/serve skew and population shift as a lesson (good material for
  "limitaciones" / "lecciones").
